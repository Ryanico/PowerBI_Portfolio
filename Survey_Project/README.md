# 📊 Data Professional Survey Breakdown | Power BI

## Project Overview

This Power BI project analyzes survey responses from data professionals across different roles, countries, and technical backgrounds. The goal of the dashboard is to explore industry trends, understand salary distributions, identify popular programming languages, and gain insights into the experiences of professionals working in data-related careers.

The dashboard transforms raw survey data into meaningful visualizations that help uncover patterns within the global data community.

---

## Objectives

The primary objectives of this project were to:

* Analyze salary trends among data professionals
* Compare compensation across different job roles
* Identify the most popular programming languages
* Explore the geographic distribution of survey respondents
* Understand career satisfaction and industry trends
* Develop an interactive business intelligence dashboard using Power BI

---

## Dataset Overview

The dataset consists of survey responses collected from data professionals and includes information such as:

* Job Title
* Average Salary
* Country
* Programming Language
* Career Satisfaction
* Work-Life Balance Satisfaction
* Difficulty Entering the Data Industry
* Unique Respondent Information

The dataset provides valuable insight into the demographics and experiences of professionals working in data-related fields.
