# PowerBI_Portfolio

# 📊 Power BI Portfolio Projects

## Overview

This repository contains a collection of Power BI projects developed while learning and applying core Business Intelligence concepts using Microsoft Power BI.

The projects cover the complete Power BI workflow, from data preparation and transformation to data modeling, DAX calculations, visualization design, and interactive reporting.

The purpose of this repository is to demonstrate practical Power BI skills commonly used by data analysts and business intelligence professionals.
